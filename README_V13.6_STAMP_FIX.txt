RIVYZA v13.6 — Stamp + regreso al perfil

- El stamp usa posts.created_at de cada publicación. No contiene una fecha fija.
- Al abrir una publicación se muestra: Publicado · [fecha y hora reales].
- Después de publicar una foto o video, la app vuelve al perfil y recarga las publicaciones.
- No requiere SQL adicional para estas dos correcciones.
